# Gestion des tâches (Python)

Application console simple pour gérer des tâches quotidiennes.
Projet réalisé en binôme : **NOM1 Prénom1** et **NOM2 Prénom2** (Licence 1 – Outils collaboratifs Git / GitHub).

## Fonctionnalités

- Ajouter une tâche (titre vide refusé)
- Afficher toutes les tâches numérotées
- Rechercher une tâche par mot-clé
- Quitter le programme (toute autre option affiche une erreur)

## Étapes réalisées

1. Création du dossier du projet dans VS Code
2. Écriture de `main.py` (menu, ajout, affichage, recherche)
3. Rédaction de ce `README.md`
4. Initialisation de Git, commits, puis publication sur GitHub

## Exécution

1. Ouvrir le dossier du projet dans VS Code
2. Ouvrir le fichier `main.py`
3. Cliquer sur le bouton **Run Python File** (▷) en haut à droite
4. Utiliser le menu dans le terminal
